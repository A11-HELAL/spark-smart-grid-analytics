# Architecture Documentation: Spec 01 (`001-hdfs-and-rdd-ops`)

This document outlines the foundation architecture, explicit schemas, and 7 core RDD operations for the Distributed Smart-Grid Demand & Tariff Analytics project.

## Directory Layout
- `src/`: Modular, pure transformation logic and centralized configuration.
- `notebooks/`: Interactive Google Colab execution runners.
- `tests/`: Local unit testing suite and lightweight sample data fixtures ($\le$ 100 rows).
- `docs/`: Technical guides, architecture records, and lab reproduction notes.
